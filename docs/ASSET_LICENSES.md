# Лицензии ресурсов

Проект не содержит ресурсов из Jujutsu Kaisen или других аниме, игр и фильмов.

| Ресурс | Источник | Лицензия/условие |
|---|---|---|
| Игровые текстуры | Генерируются в `BootScene.ts` | Часть исходного кода проекта |
| Иконки PWA | Генерируются локально скриптом `scripts/generate-icons.mjs` | Часть исходного кода проекта |
| Звуковые сигналы | Синтезируются Web Audio API | Не используют аудиофайлы |
| Russo One, Inter | Google Fonts | SIL Open Font License |

Перед коммерческой публикацией рекомендуется локально разместить файлы шрифтов и сохранить тексты их лицензий в репозитории.

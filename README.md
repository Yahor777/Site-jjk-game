# Curse Breaker: Night District

Оригинальный мобильный action-roguelite о молодом экзорцисте, который очищает ночной район от проклятых духов. Игра вдохновлена динамикой жанра, но не использует персонажей, названия, изображения или музыку сторонних аниме-франшиз.

## Возможности

- 2D-платформенные арены, рывок, ближняя атака и энергетическая техника.
- Четыре типа противников, шесть комнат и финальный босс.
- Выбор временных усилений между аренами.
- Сенсорное multi-touch управление и клавиатура.
- Постоянные осколки, рекорд и победы в `localStorage`.
- Устанавливаемое PWA с offline-кэшем.
- Адаптация под горизонтальный экран и Safe Area iPhone.

## Публикация игры на GitHub Pages

Репозиторий проекта: <https://github.com/Yahor777/Site-jjk-game>. После слияния pull request workflow `.github/workflows/deploy-pages.yml` автоматически собирает игру и публикует её как сайт.

1. Откройте в репозитории **Settings → Pages**.
2. В поле **Source** выберите **GitHub Actions**, если этот вариант ещё не выбран.
3. Откройте вкладку **Actions** и дождитесь зелёного запуска `Deploy game to GitHub Pages`.
4. Игра будет доступна по адресу:

   <https://yahor777.github.io/Site-jjk-game/>

При следующих изменениях публикация будет обновляться автоматически после push или слияния pull request в `main`.

## Запуск на компьютере

```bash
npm install
npm run dev
```

Откройте адрес, показанный Vite, обычно `http://localhost:5173`.

## Запуск на iPhone в одной Wi-Fi-сети

1. Подключите iPhone и компьютер к одной Wi-Fi-сети.
2. Запустите `npm run dev`. Сервер уже слушает `0.0.0.0`.
3. Узнайте локальный IPv4 компьютера:
   - Linux: `hostname -I`
   - macOS: `ipconfig getifaddr en0`
   - Windows: `ipconfig`
4. Откройте на iPhone в Safari адрес вида `http://192.168.1.50:5173`.
5. Если страница не открывается, разрешите порт 5173/Node.js в firewall и убедитесь, что роутер не использует изоляцию клиентов.

> Для надёжной установки PWA и offline-режима разместите production-сборку на HTTPS-хостинге (Cloudflare Pages, Netlify, Vercel или GitHub Pages). Локальный HTTP нужен прежде всего для разработки.

## Установка на главный экран iPhone

1. Откройте HTTPS-версию игры именно в Safari.
2. Нажмите **Поделиться**.
3. Выберите **На экран «Домой»**.
4. Запускайте игру через созданную иконку в горизонтальной ориентации.

## Управление

| Действие | Телефон | ПК |
|---|---|---|
| Движение | ◀ / ▶ | A / D |
| Прыжок | ПРЖ | Space |
| Атака | АТК | J |
| Рывок | РЫВ | K |
| Техника | ТЕХ | L |
| Пауза | переход в фон | Escape |

Техника расходует 25 единиц энергии. Энергия восстанавливается попаданиями по врагам.

## Production

```bash
npm run build
npm run preview
```

Перед запуском и сборкой PNG-иконки PWA автоматически генерируются из текстового Node.js-скрипта. Это позволяет переносить проект через Codex без неподдерживаемых бинарных файлов.

Собранные файлы находятся в `dist/`.
